# Evolutionary Game Theory

Making a evolutionary game theory "system" to start playing with

# Setup

## Windows

Have administrative privileges and run from cmd

```sh
python -m venv --clear --prompt evogt venv
venv\Scripts\activate.bat
pip install -e .
```

## Bash

```sh
python3.11 -m venv --clear --prompt evogt venv
. venv/bin/activate
pip install -e .
```
